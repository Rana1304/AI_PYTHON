# 🤖 AI with Python

A collection of practical **Artificial Intelligence projects and experiments built with Python**, focusing on **LLMs, APIs, conversational AI, prompt engineering, and Gradio**.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Rana1304/AI_PYTHON.git
cd AI_PYTHON
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it:

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure API Keys

Create a `.env` file in the project directory:

```env
GOOGLE_API_KEY=your_api_key_here
```

Never commit your `.env` file to GitHub.

### 5. Run a Project

Open the required Python file or notebook and run it.

For a Gradio application:

```bash
python app.py
```

The application will provide a local Gradio interface that you can open in your browser.

## 🔐 Environment Variables

For security, API keys should be stored in `.env`:

```env
GOOGLE_API_KEY=your_api_key
```

Add `.env` to `.gitignore`:

```gitignore
.env
venv/
__pycache__/
```
